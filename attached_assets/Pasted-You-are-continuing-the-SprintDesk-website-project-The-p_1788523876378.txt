1. CREATE THE DESIGN TOKEN SYSTEM
==================================================

Create reusable design tokens for:

Colors
Typography
Spacing
Border radius
Shadows
Borders

Breakpoints

The visual system should use:

Background:
Deep near-black / charcoal

Surface:
Slightly elevated charcoal surfaces

Primary accent:
Premium indigo or violet

Secondary accent:
Restrained blue/cyan for interactive data and product highlights

Text:
High contrast off-white

Secondary text:
Muted gray

Do not overuse gradients.

Do not make every section look like a floating glass card.

Use glass effects only for specific UI moments such as:

- Sticky navigation
- Floating interface panels
- Interactive overlays
